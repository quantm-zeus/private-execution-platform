# Phase 0 public/private web artifact boundary

The web layer is partitioned into three physically separate packages:
1. `web/public`: Public SolidStart site, built with no cross-imports into private workspaces. Scanned for accidental private execution terms and source maps.
2. `web/workspace-shell`: Neutral, cleartext bootstrap shell served outside the ciphertext. Delivered under fail-closed security constraints: strict own-origin CSP (`default-src 'self'`, `connect-src 'self'`, `object-src 'none'`, `base-uri 'none'`), `Cache-Control: no-store`, `X-Content-Type-Options: nosniff`, no source maps, no external analytics or third-party network dependencies. It contains only the bootstrap/UI needed for the memory-only unlock/decrypt flow and audited WASM binding loading (`crypto-envelope-wasm`), encoding zero private trading semantics and importing zero private payload modules.
3. `web/workspace-payload`: Private Solid/Vite workspace application. Packed and sealed into `web/workspace-artifact/blob.bin`.

The sealed workspace artifact is generated by packaging payload build output (`web/workspace-payload/dist`) and sealing it to the recipient workspace public key (`WORKSPACE_PUBLIC_KEY_B64`) with non-zero key ID (`WORKSPACE_ARTIFACT_KID_B64`). The build pipeline never receives or holds private/unlock key material. The legacy build key `WORKSPACE_ARTIFACT_KEY_B64` is strictly forbidden and rejected across all scripts and boundaries.

Plaintext payload build output is removed immediately after artifact packaging. Executable boundary proofs enforce shell/payload circular-bootstrap prevention, payload-only sealed archives, shell security properties, forbidden key rejection, and no plaintext leakage.

## Production static shell host contract

HTML `<meta>` directives inside `web/workspace-shell/index.html` provide defense-in-depth fallbacks but do not enforce HTTP response headers (`Cache-Control: no-store` and `X-Content-Type-Options: nosniff` are ignored by browsers in `<meta http-equiv>` tags, and CSP meta tags cannot enforce header-level policies like frame ancestors).

To enforce transport-level guarantees, the cleartext shell distribution (`web/workspace-shell/dist`) includes a standard static-host header artifact (`_headers`). Any production static hosting provider serving the shell MUST satisfy the following host contract:

1. **Header file consumption**: The static hosting infrastructure must parse `dist/_headers` (standard Cloudflare Pages / Netlify convention) and inject the configured HTTP response headers into all HTTP responses.
2. **Path coverage**: The rule for wildcard pattern `/*` applies universally to both the entrypoint document (`/`, `/index.html`) and all static assets (`/assets/*`).
3. **Mandatory response headers**:
   - `Cache-Control: no-store`: Ensures that cleartext bootstrap shell HTML, loader scripts, and WebAssembly binaries are never cached in browser storage or intermediary CDN/proxy caches.
   - `X-Content-Type-Options: nosniff`: Forbids MIME-sniffing for all served responses.
   - `Referrer-Policy: no-referrer`: Forbids sending referrer information on any outgoing navigation or subresource requests.
   - `Content-Security-Policy: default-src 'self'; script-src 'self' 'wasm-unsafe-eval'; style-src 'self'; img-src 'self' data:; font-src 'self'; connect-src 'self'; frame-src blob:; object-src 'none'; base-uri 'none'; form-action 'self'`: Restricts script, style, image, font, and fetch access strictly to the shell's own origin, permitting `'wasm-unsafe-eval'` exclusively for compiling the vendored crypto envelope WebAssembly module, with frame navigation restricted strictly to decrypted in-memory `blob:` payload documents and no external domains or unconstrained wildcards allowed.
4. **Header precedence**: The host must override any conflicting default caching or MIME headers with these directives.
5. **Payload boundary isolation**: The static-serving header artifact (`_headers`) and shell-specific configurations belong exclusively to the cleartext shell distribution. The encrypted payload archive (`web/workspace-artifact/blob.bin`) must NEVER contain `_headers` or shell bootstrap artifacts.
